# NovaImg - Repositorio de Recursos Gráficos para NovaPlay

Este repositorio centraliza y aloja todos los activos visuales, logotipos y recursos gráficos utilizados por el ecosistema **NovaPlay**.

## 📂 Contenido del Repositorio

### 📺 Logotipos de Canales
Colección optimizada de iconos para la lista de canales de la aplicación.
*   **Formato**: Se recomienda el uso de `.webp` o `.png` con fondo transparente o negro sólido.
*   **Optimización**: Las imágenes deben estar procesadas para ocupar el mínimo espacio posible sin perder legibilidad en pantallas de TV.

### 🖼️ Recursos de Interfaz (UI)
Activos utilizados en diferentes secciones de la app:
*   **Fondos**: Imágenes para el Splash Screen y pantallas de carga.
*   **Placeholders**: Imágenes por defecto para cuando un logo no está disponible.
*   **Banners**: Gráficos informativos para notificaciones y mensajes de mantenimiento.

## 🚀 Uso como CDN

Todos los recursos se sirven a través de la infraestructura de GitHub Raw, lo que permite a la aplicación NovaPlay cargar las imágenes de forma dinámica mediante URLs directas:

`https://raw.githubusercontent.com/novaplaytv/novaimg/main/[ruta_de_la_imagen]`

## 🛠️ Guía para Colaboradores

1.  **Nomenclatura**: Usar nombres descriptivos en minúsculas y sin espacios (ej: `logo_discovery_channel.webp`).
2.  **Dimensiones**: Para logos de canales, se recomienda un tamaño estándar de 300x300px o 512x512px para asegurar nitidez en resoluciones 4K.
3.  **Compresión**: Utilizar herramientas de compresión antes de subir nuevos archivos para mantener el repositorio ligero.
